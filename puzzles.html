Basic math

You are told about a polynomial $p(x)=a_{n}x^{n}+a_{n-1}x^{n-1}+\ldots+a_{1}x+a_{0}$ where $a_{i} \in \mathbb{Z}$, $a_{i}\geq {0}$, and $\max a_{i}=100$ (${0 \leq i \leq n}$).
You can provide an integer query $x$ to get the output $p(x)$.
Let $\alpha$ be the minimum number of such queries you need to make to uniquely determine the polynomial, and let $\beta$ be the minimum value of a query. Then $\alpha + \beta$ equals ____

We know that each $a_{i}$ is less than or equal to 100.

Hence the number $a_{n}a_{n-1}\dots a_{1}a_{0}$ in base $b$, where $b\geq101$ when converted to base $10$ will be unique and equal to $p(b)$.

So we require only one query with value 101 to uniquely determine the polynomial.

Thus, the final answer is $1 + 101 = 102$.
